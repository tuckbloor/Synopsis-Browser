# Synopsis V1.4.3 - Console Capture Reliability

V1.4.3 fixes Console capture so JavaScript execution diagnostics are visible in the custom Synopsis Console.

## Changes

- Uncaught JavaScript exceptions are now written to Console as well as Error Centre / AI Code Review.
- Added a page-side WebView2 message bridge for `console.log`, `console.info`, `console.warn`, `console.error`, and `console.debug`.
- Added capture for uncaught `window.error` events and unhandled Promise rejections.
- The existing Chrome DevTools Protocol capture remains enabled.
- A short duplicate-suppression window prevents the CDP and page bridge from showing the same message twice.

## LAB test

Open LAB and verify:

1. RUN CONSOLE TEST -> log, warning, and error rows appear in Console.
2. THROW EXCEPTION -> the uncaught exception appears in Console and Error Centre / AI Code Review.
3. RUN FAILED FETCH -> Network records the failed request and Error Centre / AI Code Review records the failure.
