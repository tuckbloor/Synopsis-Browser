# Synopsis V1.4.2 - Error Code Review

V1.4.2 reduces AI Diagnosis to a simple developer workflow:

1. Synopsis captures real browser/server errors.
2. The AI Diagnosis tab lists each error.
3. Click an error.
4. Synopsis resolves the linked project for that site/port.
5. Synopsis reads the best matching source excerpt and recent server-log evidence it can find.
6. Ollama reviews that evidence and returns a likely root cause, explanation, possible fix and suggested code.
7. The review is stored against that specific error. Use **REVIEW AGAIN** to regenerate it.

## Reliability changes

- Ollama is no longer forced to return strict JSON. Synopsis uses a small, section-based plain-text protocol and a tolerant parser, so a useful review is not discarded because of a missing JSON bracket.
- WebView2 `about:blank` `ConnectionAborted` lifecycle noise is filtered from the developer error inbox.
- Existing project links are re-inspected at startup so framework and log-file metadata improve automatically after Synopsis upgrades.
- When an exact source path cannot be resolved, Synopsis performs a bounded search of likely source roots using URL/error terms and supplies up to three candidate excerpts to Ollama.
- Hashed Vite/webpack asset names such as `app-ABC123.js` can fall back to a linked source file such as `app.js`.

Synopsis remains read-only: AI code review can suggest code but never edits linked source files automatically.
