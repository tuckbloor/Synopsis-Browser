# Synopsis V1.4.1 - Developer Workspace & Project Link Controls

## Resizable developer workspace

The docked Synopsis Developer Tools workspace now has a visible resize header.

- Drag **DRAG TO RESIZE** vertically to resize the whole developer workspace, including Console, Network, AI Diagnosis and Project.
- **SHRINK** reduces the dock height in a controlled step.
- **EXPAND** increases the dock height in a controlled step.
- **HIDE** collapses the workspace while preserving all current diagnostics and selections.
- The dock height is remembered for the next run.

## Detachable developer tools

**DETACH** moves the existing `DevTabs` instance into a separate WPF window. It does not create a second copy of the console or diagnostics state.

This means Console history, Network requests, selected AI incident, project information and other tool state remain intact when moving between docked and detached modes.

Closing the detached window, or pressing **DOCK BACK**, reattaches the same developer workspace to the main browser.

## Project link visibility and unlinking

The Project tab now explicitly shows:

- current linked site/authority
- exact linked directory
- detected framework
- detected development log

**UNLINK** removes only Synopsis's saved project mapping and its associated log watcher. It does not delete, move, rename or modify the linked project directory or any project files.
