# Synopsis V1.1.0 Browser Shell

This maintenance release repairs the browser chrome and navigation flow before further V2 expansion.

- Vector back/forward/reload/home controls.
- Large independent omnibox with visible GO button.
- Enter navigates and Escape restores the current URL.
- Ctrl+L selects the omnibox.
- Ctrl+T opens a new tab ready for typing.
- Built-in branded start page.
- ASCII-safe source labels to prevent mojibake after Windows script edits.
- All first Windows compiler fixes included.
- OPEN-SYNOPSIS.cmd avoids PowerShell execution-policy problems.
