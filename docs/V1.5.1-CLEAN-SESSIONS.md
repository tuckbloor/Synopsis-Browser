# Synopsis V1.5.1 - Clean Sessions

## CLEAR ALL

The global CLEAR ALL control resets transient developer evidence:

- Console
- Network requests
- Error Centre
- AI incidents and stored reviews
- API / response body
- Performance counters derived from Network data
- Current Security/TLS snapshot
- Current selections and AI source/log preview

It deliberately preserves persistent user data:

- browser/AI settings
- Ollama model/provider configuration
- bookmarks
- saved project links
- linked project files/directories

## Automatic clear on a new omnibox URL

When the developer types a different URL/search into the address bar and presses Enter or GO, Synopsis clears the previous transient diagnostic session before navigation. This prevents evidence from one site being mixed with the next.

Normal page-to-page navigation initiated inside a website is not cleared automatically.

## Source launcher

Double-click `OPEN-SYNOPSIS.cmd` from the fully extracted project root. It restores the solution and runs Synopsis with `dotnet run` from `src/SynopsisBrowser.App`. It does not use the `publish` or `dist` folders.
