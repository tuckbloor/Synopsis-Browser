# Synopsis V1.4 AI Error Workbench

The AI Diagnosis tab is an incident workbench rather than a single global result panel.

## Workflow

1. Synopsis captures browser/server Error or Critical diagnostics.
2. Every real error is added to the AI inbox.
3. The developer selects the error they want to investigate.
4. Synopsis resolves the linked project by URL authority (including localhost port) with a legacy host-only fallback.
5. If a project is linked, Synopsis searches the diagnostic/stack trace and recent linked log for referenced source files.
6. When a source file is resolved, Synopsis reads a bounded excerpt around the relevant line.
7. Synopsis displays that evidence in the UI before it is sent anywhere.
8. Secrets are redacted.
9. The selected error plus bounded source/log evidence is sent to Ollama only when **ANALYSE ERROR** is clicked, unless optional background Auto AI is enabled.
10. The recommendation is stored against that exact diagnostic ID.

Synopsis does not send an entire project tree to Ollama. It sends bounded evidence relevant to the selected incident.
