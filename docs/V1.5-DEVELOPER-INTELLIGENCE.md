# Synopsis V1.5.0 - Developer Intelligence

V1.5 turns AI Code Review from an error list into an incident-oriented debugging workspace.

## Incident correlation

Synopsis still records every Error/Critical diagnostic in Error Centre, but AI Code Review groups related signals into an incident when there is strong evidence they belong together:

- identical Chromium request/correlation IDs
- the same URL/source within a short window
- closely timed HTTP + network failures
- closely timed console + JavaScript exception signals
- closely timed linked server-log exceptions

The incident list shows the number and kinds of related signals. Reviews are invalidated if new evidence joins an incident after an earlier review.

## Three-column review workspace

AI Code Review is now arranged as:

1. **Incident** - correlated browser/server signals
2. **Source** - resolved linked source, source-map result, recent server logs, and full evidence
3. **Ollama review** - root cause, confidence, explanation, possible fix, code, and investigation steps

Selecting an incident starts a quick code review if no stored review exists. **QUICK REVIEW** regenerates a bounded review; **DEEP REVIEW** gives the selected model a larger response/context budget.

## Source maps

When Chromium reports a generated JavaScript location and the linked project has a Source Map v3 file, Synopsis attempts to decode the generated line/column back to the original source file/line/column. Source-map resolution is read-only and never executes project code.

If source maps are unavailable, Synopsis falls back to exact stack-trace paths, URL-to-project mapping, unhashed asset-name matching, linked server logs, and a bounded source search.

Synopsis no longer treats a generated Vite bundle line as though it were automatically the same line in `resources/js/app.js` when no map exists.

## Failed HTTP response evidence

For failed HTTP requests, Synopsis attempts to capture a bounded response-body preview after loading completes. The response body joins the same request incident by Chromium request ID. This gives code review access to useful Laravel/API evidence such as validation JSON and exception responses.

## Safety

V1.5 remains read-only:

- reads linked source excerpts
- reads recent linked logs
- reads browser/network diagnostics
- asks Ollama for review/fix suggestions
- can open the resolved source file in VS Code

It does **not** modify source files, execute proposed fixes, delete project files, or run project commands.
